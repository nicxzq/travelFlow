# TravelFlow 迭代升级日志

## v1.1.0 - 2026-08-31

### 定位

把目的地地图从「示意图」升级为真实地图与行程轨迹回放，并把这套结构定为后续所有行程的规划、管理、展示、归档标准。

### 新增

- 引入 `leaflet@^1.9.4`（`next/dynamic` + `ssr:false` 动态分包），替换原 OSM iframe 假地图。
- 新增 `buildJourneyTrack(trip, overlay)`：轨迹从 `events[].geo` 派生，不再依赖平行维护的点位清单。
- 新增轨迹动画播放器：右上角「轨迹动画」按钮，小车沿路线行进，已走过的路持续叠加为绿色实线并跨天保留。
- 新增全屏按钮：portal 浮层 + 三面板布局（左天数轨 / 右故事卡 / 底部播放器）。
- 新增关键景点图片支持：故事卡展示图片、时间、标签与故事文本。
- 新增「编辑」弹窗：按天折叠填写图片网址 / 标签 / 故事，存 `localStorage`，支持 JSON 导入导出与恢复默认。
- 新增行程 `shanxi-actual-2026`（成行版，2026-08-16 至 08-21，17 站全部带坐标），入口在 `/trip`。
- 新增 `TripEvent.transportMode`：飞行段不请求驾车路由。

### 变更

- `DestinationMap` 改为接收 `trip` 而非点位数组；标题从硬编码「长治目的地地图」改为通用「目的地地图」。
- `lib/mock/shanxi-loop.ts` 的 37 个事件补齐 `geo`。
- 删除 `lib/mock/destination-map.ts`（含「长治」字符串硬匹配）。
- `scripts/validate-scaffold.mjs` 同步更新断言并新增轨迹模块断言。

### 已知限制

- OSRM 为公共 demo 服务，仅作渐进增强；失败时回落示意路线，不阻断播放。服务端路由代理待后续版本。
- 覆盖层仅存本浏览器，跨设备同步需等 Supabase 写库落地。
- 地图画布在嵌入态与全屏态间切换时会 remount，几何与车辆位置由容器重放。

### 验证

- `npm run typecheck`、`npm run lint`、`npm test`、`npm run build` 全绿
- 路由 200：`/`、`/trip`、`/trip/shanxi-actual-2026`、`/trip/shanxi-loop-2026`、`/trip/shanxi-actual-2026/share`
- 产物确认 `leaflet.css` 独立 CSS chunk；分享页 `readOnly` 不渲染编辑入口

## v1.0.0 - 2026-08-13

### 定位

面向真实出行的 P0 版本：先让 `travel.carlxu.cn` 能稳定展示晋东南到晋南自驾环线，支持同行查看、当天导引和本地生成记录管理。

### 新增

- 首页改为用户可读的旅行助手介绍，突出“今天去哪、明天准备什么、同行同步”。
- 首页增加轻量动效卡片、当前行程入口、同行分享页入口。
- 底部增加管理员咨询信息：`carl-xu`。
- 底部增加版本号：`1.0.0`。
- 新增 `/trip` 行程管理页，集中展示已准备行程和浏览器本地保存记录。
- 新增 `shanxi-loop-2026` 静态行程数据，覆盖 2026-08-15 至 2026-08-20 的 6 天 5 晚自驾环线。
- 新增当天/明天导引逻辑，按 `Asia/Shanghai` 计算行前、行中、行后状态。
- 新增可复用 `TripWorkspace`，详情页和同行分享页共用同一份展示逻辑。
- 事件卡片支持外部导航链接，无高德 Key 时通过地图 URI / Web 搜索降级。
- 创建页增加热门 2 日游随机提示。
- 创建页增加 toast 操作反馈和生成进度条。
- 创建页默认显示渲染后的行程内容，代码按钮可切换可编辑 JSON。
- “基于画布二次完善”改为“按当前结果继续优化”。
- “不满意，重新生成”在首次创建行程前置灰。

### 变更

- 顶栏入口从“自驾环线”调整为“行程”，符合长期信息架构。
- `/trip/[id]` 从单日 mock 时间线升级为“总览 + 当日导引 + 待办 + 明日预告 + 完整行程”。
- `/trip/[id]/share` 从占位页升级为同行只读同步页。
- 创建页说明文案从技术说明改为用户任务说明。

### 验证

- `npm test`
- `npm run typecheck`
- `npm run lint`
- `npm run build`
- 本地路由 200 验证：`/`、`/new`、`/trip`、`/trip/shanxi-loop-2026`、`/trip/shanxi-loop-2026/share`

### 已知限制

- 本地生成记录仍保存在浏览器 localStorage，换设备不可见。
- 晋东南到晋南自驾环线目前是静态 seed 数据，未接 Supabase 云端编辑。
- 同行分享页当前只读，不支持上传照片或多人编辑。
- 图片、语音、游记归档和登录权限进入后续 Supabase 同步阶段。
