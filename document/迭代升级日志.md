# TravelFlow 迭代升级日志

## v1.0.0 - 2026-08-13

### 定位

面向真实出行的 P0 版本：先让 `travel.carlxu.cn` 能稳定展示晋东南到晋南自驾环线，支持同行查看、当天导引和本地生成记录管理。

### 新增

- 首页改为用户可读的旅行助手介绍，突出“今天去哪、明天准备什么、同行同步”。
- 首页增加轻量动效卡片、当前行程入口、同行分享页入口。
- 底部增加管理员咨询信息：`carl-xu`。
- 底部增加版本号：`1.0.0`。
- 新增 `/trip` 行程管理页，集中展示已准备行程和浏览器本地保存记录。
- 新增 `shanxi-loop-2026` 静态行程数据，覆盖 2026-08-15 至 2026-08-20 的 6 天 5 晚自驾环线。
- 新增当天/明天导引逻辑，按 `Asia/Shanghai` 计算行前、行中、行后状态。
- 新增可复用 `TripWorkspace`，详情页和同行分享页共用同一份展示逻辑。
- 事件卡片支持外部导航链接，无高德 Key 时通过地图 URI / Web 搜索降级。
- 创建页增加热门 2 日游随机提示。
- 创建页增加 toast 操作反馈和生成进度条。
- 创建页默认显示渲染后的行程内容，代码按钮可切换可编辑 JSON。
- “基于画布二次完善”改为“按当前结果继续优化”。
- “不满意，重新生成”在首次创建行程前置灰。

### 变更

- 顶栏入口从“自驾环线”调整为“行程”，符合长期信息架构。
- `/trip/[id]` 从单日 mock 时间线升级为“总览 + 当日导引 + 待办 + 明日预告 + 完整行程”。
- `/trip/[id]/share` 从占位页升级为同行只读同步页。
- 创建页说明文案从技术说明改为用户任务说明。

### 验证

- `npm test`
- `npm run typecheck`
- `npm run lint`
- `npm run build`
- 本地路由 200 验证：`/`、`/new`、`/trip`、`/trip/shanxi-loop-2026`、`/trip/shanxi-loop-2026/share`

### 已知限制

- 本地生成记录仍保存在浏览器 localStorage，换设备不可见。
- 晋东南到晋南自驾环线目前是静态 seed 数据，未接 Supabase 云端编辑。
- 同行分享页当前只读，不支持上传照片或多人编辑。
- 图片、语音、游记归档和登录权限进入后续 Supabase 同步阶段。
